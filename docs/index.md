# Knowledge base

An [Open Knowledge Format](https://github.com/GoogleCloudPlatform/knowledge-catalog/tree/main/okf)
(OKF) bundle — Markdown + YAML frontmatter, one concept per file. Query it with okq:

    okq find --type adr
    okq search "<topic>"
    okq stats

Folders: `adrs/` (decisions), `features/` (specs), `workflows/` (end-to-end
operator flows), `external/` (verbatim snapshots of specs owned elsewhere).
